# Release statement

Released in this folder, under the repository's MIT licence:

- The C++ CBF core and Python wrapper (`safety-filter/`).
- The ZenoGuard, the schema validator, the rule-based intent generator and the RAN
  simulator used for the conference version.
- The unit tests in `tests/`, and the documentation files listed in `README.md`.

To be released by the author before the camera-ready deadline (7 November 2026). Each
item below must be either published or explicitly excluded, with the reason:

- Raw per-episode results of the 50-run campaign (not present in this snapshot).
- The configuration files and random seeds used for each reported number.
- The exact tau_min value used for the reported results (see `ASSUMPTIONS.md`, section 5).
